【POS 電文驗証平台】執行方法
===============================

✅ 第一次使用前：
1. 確認已安裝 Node.js (https://nodejs.org)
2. 確認已安裝 Python 3 (https://python.org)
3. 在此資料夾按右鍵 → 「在終端機中開啟」

4. 安裝前端依賴：
   npm install

5. 安裝 Python 依賴：
   pip install websockets

===============================

🚀 每次使用時（開兩個終端機視窗）：

【終端機 1】啟動 ADB 橋接服務：
   python adb_bridge.py

【終端機 2】啟動前端介面：
   npm run dev

然後用瀏覽器開啟：http://localhost:3001

===============================

📌 注意事項：
- 兩個服務都要同時執行才能正常使用
- ADB 設備需先連接並信任電腦
- pos_rules.json 為規格設定檔，會自動存檔
